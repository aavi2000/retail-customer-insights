# Retail Customer Insights

A portfolio case study exploring customer purchasing patterns
using Python, SQL and Power BI.

## Business Questions
- How does purchase amount vary across customer segments?
- How do discounted and non-discounted purchases differ?
- Which product categories show the strongest purchasing activity?

## Tools
- Python: data exploration and preparation
- SQL: business analysis
- Power BI: dashboard visualization

## Project Status
Currently adapting the source project and validating its results.

## Planned Extensions
